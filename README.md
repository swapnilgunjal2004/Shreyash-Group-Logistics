SG Logistics is a trusted transport and logistics partner delivering reliable, efficient, and timely cargo solutions across India.

---

## 🚀 Getting Started

### Prerequisites

Make sure you have **Node.js** (v16 or later) and **npm** installed.

- Download Node.js: https://nodejs.org

Verify your installation:

```bash
node --version
npm --version
```

---

### Installation

Clone the repository and install dependencies:

```bash
git clone https://github.com/swapnilgunjal2004/Shreyash-Group-Logistics.git
cd Shreyash-Group-Logistics
npm install
```

---

### Running the Project

#### Development server

```bash
npm run dev
```

This starts a local server at **http://localhost:3000**.  
Open that URL in your browser to view the site.

#### Production server

```bash
npm start
```

Same as `npm run dev` — serves the static site on port 3000.
